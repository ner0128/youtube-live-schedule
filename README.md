# youtube-live-schedule

유튜브 라이브 일정 PC 프로그램(Windows)의 요구사항 명세와 테스트 기록입니다.

등록한 유튜브 채널의 예약·방송 중 라이브를 한국 시간으로 모아 보여 주는 프로그램으로, 개인적으로 만들어 실제로 쓰고 있습니다.

## 역할 분담

| 작업                 | 담당          |
| ------------------ | ----------- |
| 앱 구현               | AI (Claude) |
| 요구사항 명세서 초안        | AI (Claude) |
| 요구사항 결정, 명세서 검토·수정 | 직접          |
| 테스트 케이스 작성         | 직접          |
| 테스트 수행 (실사용 PC)    | 직접          |
| 결함 리포트             | 직접          |
